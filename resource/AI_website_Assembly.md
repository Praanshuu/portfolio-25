# AI-Assisted Modular Website Builder Using Semantic Component Assembly

Developed an AI-assisted website generation system that automates webpage creation using semantic similarity techniques and modular UI assembly.

The system accepts user inputs such as business type, target audience, and website purpose, then retrieves semantically relevant UI components using vector embeddings and pgvector similarity search. Retrieved components are automatically assembled into responsive webpage layouts through a custom assembly engine with layout ordering and style harmonization.

Built using React.js/Next.js, Node.js, Express.js, PostgreSQL/Supabase, Tailwind CSS, and Sentence Transformer embeddings.

Key features include:

* Semantic component retrieval
* Automated webpage assembly
* Responsive UI generation
* Live preview system
* Exportable frontend code
* Modular component architecture

The project demonstrates the practical application of AI, semantic search, vector databases, and modular frontend systems in intelligent web development workflows.
